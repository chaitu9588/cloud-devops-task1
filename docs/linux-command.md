# LINUX COMMAND-LINE PRACTICE
# I have practiced following linux commands:

1.	pwd – prints Working Directory.
2.	ls – lists normal files and directories.
3.	ls -la – list all files, including hidden files, in detailed format.
4.	mkdir – create directory.
5.	touch – create files.
6.	cat – used to read file content.
7.	cat >> -- used to append data into the existing file.
8.	cp – copies the file itself, including its contents and relevant metadata.
9.	mv – used command to move file from one location to desired location.
10.	rm – command used to delete file.
11.	grep – used to search specific word in a file.
12.	find – used this command to find type of file in a desired location.
    Ex. find . -type f -name "*.txt"
13. chmod – using this command I have given execution permission to the file.
    Ex: chmod +x permission-test.sh
    And it is verified using command: ls -l permission-test.sh 
14. ps – usually shows processes related to your current shell( What processes are running in my current terminal?).
15. ps -aux – shows processes from all users, along with CPU and memory usage (detailed snapshot of all processes).
16. top – live monitoring.
    NOTE:     ps → snapshot 
              ps aux → detailed snapshot of ALL processes 
              top → live monitoring
17.	apt search <package-name> -- used to search for available packages.
18.	apt policy <package-name> -- used to check the installed version, available version, and repository/source of a package in Ubuntu/Debian.
